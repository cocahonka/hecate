# Hecate
> End-to-End чат на базе YubiKey.

**Hecate** — концепт десктопного чат-клиента, использующего аппаратный ключ YubiKey в качестве основы для end-to-end шифрования. Архитектура будет построена по принципу "нулевого знания" на сервере, где все сообщения и ключи чатов хранятся в зашифрованном виде. Доступ к данным возможен только при физическом наличии YubiKey, который хранит приватный ключ пользователя и выполняет все криптографические операции по расшифровке.
